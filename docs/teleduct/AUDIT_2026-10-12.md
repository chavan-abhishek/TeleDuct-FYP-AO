# TeleDuct code-audit correction — 2026-10-12

Source: repository `chavan-abhishek/TeleDuct-FYP-AO`, main `37be6f4` (verified via GitHub connected repository). This is **static code inspection**, not a GPU/stack test. Agent audit claims and actual verification are deliberately separated.

## Present and reusable
- `Layer_A/gpu_poller.py`: NVML device-level sampling every configurable interval.
- `Layer_A/sglang_scraper.py`: Prometheus metrics polling.
- `Layer_A/logit_processor.py`: torch processor prototype, `softmax`, top-k, margin; runtime registration with SGLang is *unverified*.
- `Layer_A/moe_capture.py`: architecture-specific monkey-patched forward hooks, not demonstrated against deployed production model.
- `layer_b/sdk/correlator.py`: PostgreSQL-backed session/node wrapper, but session ID + step counter held on a mutable instance: audit concurrency safety and node exceptions.
- `layer_b/storage/init.sql`: 7-table SQL schema.
- `infra/local_hub/docker-compose.yml`: local PostgreSQL, OTel Collector, Prometheus, Grafana stack.

## Findings requiring fixes, not feature claims
1. **Synthetic logit fallback** (`layer_b/demo_agent/run_live_agent.py`): initializes `margin=0.50`, `top_probs=[0.85,0.15]`, `top_ids=[101,102]` then may store these as live telemetry if response has no suitable logprobs. Replace missing with NULL / status=`unavailable`; do not emit a confidence/fragility verdict without measured candidates. Do not describe global next-token margin as calibrated confidence in tool choice.
2. **Synthetic MoE benchmark** (`Layer_A/scripts/benchmark_moe_stress.py`): explicitly fabricates expert loads/margins. Label entire event stream `synthetic`; never cite this benchmark as successful real expert-hook capture.
3. **OTel collector is not a joiner** (`infra/local_hub/otel-collector-config.yaml`): spans go to logging and metrics to Prometheus; it does not perform trace identity joins nor export correlated relational records to PostgreSQL. Implement a separate fusion/normalization service.
4. **NVML measurements are device-wide** (`Layer_A/gpu_poller.py`): utilization, total VRAM and power are shared-device samples, not per-request direct attribution. `util.memory` is GPU memory-controller utilization, not measured effective bytes/s.
5. **No guaranteed shared context propagation**: `Layer_A/context.py` defines process-local ContextVar, and `layer_b/sdk/correlator.py` maintains its own session ID; separate hosts/processes require explicit propagation of request identity. Demonstrate a real join end-to-end.
6. **Unsafe defaults for network-exposed environments**: `infra/local_hub/docker-compose.yml` embeds demonstration PostgreSQL and Grafana credentials and publishes ports by default. Replace them in the infra workstream with `.env`-backed secrets and bind to loopback for laptop use; do not expose to public internet. Rotate credentials if reused anywhere beyond dev.
7. **Overclaims in docs**: EU AI Act conformance, immutable/tamper-evident records, perfect root-cause inference, and kernel-level exact attribution are not demonstrated. Describe hypotheses and proof obligations. The `0.05` margin is a heuristic, not validated risk calibration.
8. **Operational environment drift**: repository docs contain Mac/RunPod remote setup and specific stale endpoint addresses. Adapt for Nobara; never check hard-coded server credentials into git.
